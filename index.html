พื้นฐาน

Claude คืออะไร และเริ่มต้นอย่างไร

Claude คือ large language model (LLM) ที่สร้างโดย Anthropic ออกแบบให้เป็นผู้ช่วยที่ helpful, honest, and harmless พร้อมน้ำเสียงแบบสนทนา

รับได้ทั้งงานง่ายและงานซับซ้อน

ตั้งแต่คำถามข้อเท็จจริงสั้น ๆ ไปจนถึงโปรเจกต์หลายขั้นตอน งานเขียนเชิงสร้างสรรค์ งานเขียนโค้ด และการวิเคราะห์เชิงเทคนิค

รองรับหลายภาษา

ผ่านการเทรนด้วยภาษาอังกฤษอย่างเข้มข้น และทำงานได้ดีในภาษาอื่นที่ใช้กันแพร่หลาย รวมถึงภาษาโปรแกรมต่าง ๆ

ปรับ model และ effort ได้

สลับไปใช้โมเดลอื่นที่มีให้ พร้อมปรับระดับ effort และ thinking settings ได้จากในหน้าจอสนทนา

ข้อกำหนดการใช้งาน — ผู้ใช้ต้องมีอายุอย่างน้อย 18 ปี และอยู่ในภูมิภาคที่รองรับ · ผู้ใช้แผน Free จะมี session-based usage limit ที่ reset ทุก 5 ชั่วโมง โดยจำนวนข้อความที่ส่งได้จะแปรผันตามภาระของระบบในขณะนั้น

Safety

ใช้ Cowork อย่างปลอดภัย

ความเสี่ยงของ agentic tool มาจากสองมิติคือ Claude อ่านอะไรได้ และ Claude ทำอะไรได้ — ภัยหลักคือ prompt injection คือคำสั่งอันตรายที่ฝังอยู่ในเนื้อหาภายนอกแล้วหลอกให้ Claude ทำตาม

ชั้นป้องกันที่มีอยู่
  • เทรนโมเดลให้ต้านคำสั่งที่เป็นอันตราย
  • Classifiers คอยจับเนื้อหาที่น่าจะเป็น injection
  • การลบไฟล์ต้องได้รับอนุญาตอย่างชัดเจน
  • Computer use มีการตรวจสิทธิ์แยกรายแอป
แนวปฏิบัติที่แนะนำ
  • จำกัดสิทธิ์เข้าถึงไฟล์ไว้ที่ folder งานที่ไม่อ่อนไหว
  • ดูภาพรวมรูปแบบของงานมากกว่าไล่ตรวจทีละคำสั่ง
  • เลี่ยงการตั้ง scheduled task กับข้อมูลอ่อนไหว
  • จำกัด browser ให้เข้าเฉพาะเว็บที่ไว้ใจได้
  • ตรวจสอบ MCP และ plugin ให้ดีก่อนติดตั้ง
  • แจ้งทันทีเมื่อเห็นพฤติกรรมผิดปกติ
Sandbox ไม่ได้กันทุกอย่าง — การรันแบบ isolated บนเซิร์ฟเวอร์ Anthropic จำกัดแค่ ว่าโค้ดถูกรันที่ไหน ไม่ได้จำกัดว่า Claude อ่านหรือทำอะไรได้ · cloud session ยังเข้าถึงไฟล์ อีเมล และ browser ของเราผ่าน Desktop app ได้อยู่ · ผู้ใช้ยังคงรับผิดชอบเต็มที่ต่อทุก action ที่ Claude ทำแทน

Configuration

เลือกและตั้งค่าโมเดลใน Claude Code

  1. เปลี่ยนเร็วที่สุด — พิมพ์ /model แล้วเลือกจากเมนู การเปลี่ยนมีผลทันที
  2. เฉพาะ session นี้ — ใส่ flag ตอนเปิดโปรแกรม เช่น claude --model claude-opus-5
  3. ตั้งเป็นค่าเริ่มต้นถาวร — เพิ่ม export ANTHROPIC_MODEL="…" ลงในไฟล์ shell config (~/.zshrc บน macOS หรือ ~/.bashrc บน Linux) แล้ว source ใหม่และรีสตาร์ต Terminal
  4. ตรวจสถานะ — พิมพ์ /status เพื่อดูว่าตอนนี้ใช้โมเดลอะไรอยู่

เชื่อมเฉพาะ server ที่ไว้ใจได้ — remote MCP server สามารถอ่าน สร้าง แก้ไข และลบข้อมูลในแอปที่เชื่อมต่อได้ตามที่ผู้พัฒนากำหนดไว้ · อ่าน OAuth permissions ให้ละเอียดก่อนกดอนุญาต และคอยติดตามว่า Claude เรียกใช้ tool อะไรบ้าง

Permissions

ระบบสิทธิ์สองชั้น: โหมด และ รายเว็บไซต์

ชั้นที่ 1 · โหมดการอนุมัติ
  • Manually approve — Claude จะหยุดเพื่อขออนุมัติก่อนทำทุก action
  • Automatically approve — ทำงานต่อเนื่องพร้อมตรวจความปลอดภัยไปด้วย และบล็อกอัตโนมัติเมื่อประเมินว่าไม่ปลอดภัย
  • Skip all approvals — ไม่มีการตรวจสอบใด ๆ ทำงานโดยไม่หยุดถาม
ชั้นที่ 2 · สิทธิ์รายเว็บไซต์
  • Allow this action — อนุญาตเฉพาะครั้งนี้
  • Always allow actions on this site — อนุญาตถาวรสำหรับเว็บนั้น ไม่ต้องถามซ้ำ
  • Decline — ปฏิเสธ action นั้น
สามอย่างที่ต้องขออนุมัติเสมอ แม้จะตั้ง “Always allow” ไว้แล้ว — การดาวน์โหลดไฟล์ · การกรอกข้อมูลที่อ่อนไหว · การให้ authorization ใด ๆ
จัดการสิทธิ์ที่ให้ไปแล้ว — เปิดเมนูการตั้งค่าของ extension แล้วไปที่หน้า Permissions เพื่อดูรายการ “Your approved sites” เพิกถอนสิทธิ์ของเว็บใดเว็บหนึ่ง และตรวจสอบประวัติการให้สิทธิ์ · admin ของแผน Team และ Enterprise ตั้ง allowlist หรือ blocklist ที่ มีผลเหนือการตั้งค่าของผู้ใช้รายคน ได้
